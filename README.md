# Guess The Number

A console-based Number Guessing Game written in C.

## How It Works
1. The program generates a secret random number between **1 and 100**.
2. You enter your guess in the terminal.
3. The game gives hints (`Higher number please!` or `Lower number please!`) until you guess correctly.
4. Once you win, it displays the total number of guesses you took.

## How to Run
Compile and run the code using `gcc`:

```bash
gcc guessno.c -o guessno
./guessno
```
